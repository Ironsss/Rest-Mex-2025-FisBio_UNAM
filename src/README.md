# Multi Task BERT for Mexican Tourism Reviews REST MEX 2025

This repository documents the research paper titled Multi Task BERT Architecture for Sentiment Analysis and Classification of Mexican Tourism Reviews in REST MEX 2025 by David Alexis Garcia Espinosa Luis Eduardo Flores Luna and Angel Andres Moreno Sanchez. The paper was published in the Proceedings of the Iberian Languages Evaluation Forum IberLEF 2025 within the CEUR WS workshop proceedings volume 4098.

The full paper is available in open access at the following address.
https://ceur-ws.org/Vol-4098/RESTMEX2025_paper5.pdf

## Research overview

The paper presents a multi task learning architecture based on BERT for the analysis of Spanish language tourism reviews written in Mexico. A single shared language model is used together with several task specific classification heads in order to perform sentiment analysis and text classification at the same time. This design allows the model to learn shared linguistic representations that are useful across related tasks while reducing training and deployment complexity.

The system was evaluated on official datasets provided by the REST MEX 2025 shared task and achieved competitive results when compared with single task baselines.

## REST MEX 2025 challenge and CIMAT

REST MEX is a shared task organized by researchers from the Centro de Investigacion en Matematicas CIMAT and collaborators. It is part of IberLEF which is co located with the SEPLN conference. The challenge focuses on sentiment evaluation and text classification for Mexican tourism reviews written in Spanish and aims to promote applied research in natural language processing for regional language variants.

The official task page maintained by CIMAT can be found at the following address.
https://sites.google.com/view/rest-mex

## Relevance of this work

This work contributes to applied natural language processing in Spanish by addressing real world data from a specific regional context. It demonstrates how multi task learning can improve model efficiency and robustness when several related predictions are required from the same text. The approach also shows how shared task benchmarks can be used to bridge academic research and practical applications.

## Use cases and applicability

Although the experiments focus on tourism reviews the proposed architecture is general and can be applied to many domains where text must be analyzed along multiple dimensions.

In medicine the same approach can be used to analyze patient feedback classify clinical notes detect sentiment in patient surveys and support pharmacovigilance through adverse event reports.

In finance it can be applied to customer complaints risk related text signals and sentiment analysis of user feedback.

In retail and electronic commerce it can support product review analysis customer satisfaction monitoring and feedback classification.

In public policy it can be used to analyze citizen opinions evaluate social programs and study public perception of policy initiatives.

In conversational artificial intelligence it can support intent detection sentiment analysis and message classification for chatbots and customer support systems.
